# Computing Research Project

A research and data analytics project focused on enhancing healthcare cybersecurity through AI-based cyber threat detection and intrusion detection systems (IDS).

## Project Overview

This project explores the use of artificial intelligence and machine learning techniques to improve cyber threat detection in hospital environments. The study focuses on identifying malicious network activity, improving detection accuracy, and reducing false positives using benchmark intrusion detection datasets.

## Features
- AI-based intrusion detection analysis
- Healthcare cybersecurity research
- Machine learning model evaluation
- Data preprocessing and cleaning
- Exploratory data analysis (EDA)
- ROC curve and confusion matrix analysis
- Cyber threat detection visualization

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Research Focus
- Healthcare cybersecurity
- AI and machine learning
- Intrusion Detection Systems (IDS)
- Cyber threat detection
- Network traffic analysis
